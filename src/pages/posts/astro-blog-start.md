这个博客先从一个很小的目标开始：把文章写舒服，把阅读体验做清楚。

第一版只保留这些页面：

- 首页：简介和最新文章
- 文章页：按时间倒序展示笔记
- 标签页：按主题回看内容
- 关于页：放个人说明和联系方式

暂时不做复杂后台，也不接数据库。文章就是 Markdown 文件，新增一篇文章只需要在 `src/pages/posts` 下面新建一个 `.md` 文件。

## 为什么先保持简单

博客最重要的是能持续写。如果一开始把编辑后台、评论系统、复杂主题都加上，维护成本会很快超过写作本身。

所以现在的原则是：

1. 页面结构清楚
2. 代码少而直接
3. 样式克制
4. 后续需要再加功能

## 示例代码块

```ts
const note = {
  title: "保持简单",
  status: "writing"
};
```
